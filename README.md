# AI Checkers 6x6

This project implements a 6x6 Checkers (Draughts) game with an AI opponent.

## Features
- 6x6 Checkers board
- AI player using Minimax with Alpha-Beta pruning
- Text-based board visualization
- Turn-based gameplay between human and AI

## Technologies
- Python 3

## How to Run
1. Make sure Python 3 is installed.
2. Run the main file:

bash
python Checkers.py

Project Structure:
Checkers.py : Main game logic and AI implementation
